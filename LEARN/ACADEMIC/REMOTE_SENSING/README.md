# Orbit Study Quest

A local, PDF-grounded gamified study application for **Sensors and Platform Characteristics**.

## Run

```powershell
npm install
npm run dev
```

Then open the local URL Vite prints (normally `http://localhost:5173`).

## Verification

```powershell
npm run build
npm run coverage
```

The coverage check confirms all 104 lesson pages are included. The searchable Lesson Notes view keeps terms, values, diagrams, figures, imagery, and specification tables together. Progress, XP, answer history, mastery, and flashcard review scheduling persist in browser local storage.

## Included modes

- Dashboard and module progression
- Learn with PDF page citations
- Cover & Check recall scoring
- Spaced-repetition flashcards
- Mixed, multiple-choice, identification, true/false, number, and classification challenges
- Boss battle mode
- Searchable study library
- Searchable lesson reference
